## 🧠 Mi forma de abordar un problema

**1. Entender la decisión**

Antes de analizar datos, identifico qué pregunta necesitamos responder y quién utilizará la información.

**2. Entender los datos**

Audito fuentes, estructura, cobertura, periodicidad, unidades, calidad y limitaciones metodológicas.

**3. Construir una fuente confiable**

Integro, limpio, valido y documento los datos antes de utilizarlos para análisis.

**4. Analizar**

Busco tendencias, relaciones, anomalías, desviaciones y señales relevantes para el problema.

**5. Comunicar**

Transformo el análisis en indicadores, visualizaciones o narrativas que permitan comprender rápidamente qué está ocurriendo.

**6. Automatizar**

Cuando el análisis debe repetirse, busco convertirlo en un proceso reproducible y escalable.
