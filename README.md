## ⚡ Proyecto destacado — Observatorio Energético Nacional

Estoy desarrollando una plataforma de **ingeniería, analítica y visualización de datos aplicada al sector energético mexicano**.

> **Problema:** la información energética se encuentra distribuida entre múltiples fuentes, formatos y metodologías, dificultando obtener una visión integrada del sector.

**Qué construyo:** una arquitectura para **ingerir, clasificar, validar, transformar y visualizar** información energética proveniente de múltiples fuentes.

**Herramientas:** `Python` · `Pandas` · `APIs` · `ETL` · `Streamlit` · `Plotly` · `Git`

**Resultado:** una plataforma analítica reproducible que integra actualmente información de **exploración, reservas, producción, transformación industrial, comercio y precios**, y evoluciona hacia **electricidad y Mercado Eléctrico Mayorista**.
